# 점심 운동 (PWA)

**앱 주소: https://jsyunn1.github.io/workout/**

평일 점심 90분(11:30~13:00) 운동 프로그램을 휴대폰에서 확인하고 기록하는 웹앱입니다.
월·수·금 웨이트, 화·목 수영(마스터즈 수준) 루틴과 4주 주기 강도 조정을 담고 있습니다.
빌드 도구와 외부 라이브러리 없이 바닐라 HTML/CSS/JS로 동작하며, 오프라인에서도 쓸 수 있습니다.

## 화면

| 탭 | 기능 |
| --- | --- |
| 오늘 | 요일별 루틴 자동 표시(주말은 휴식), 점심 타임라인과 현재 단계 강조, 세트 체크·중량·RPE 입력, 휴식 타이머(진동·소리), 운동 완료 기록 |
| 주간 계획 | 월~금 계획표, 1~4주차 선택, 주차별 세트·RPE·수영량 조정 표시(바뀐 값은 주황색) |
| 기록 | 날짜별 완료 내역, 운동별 중량 추이 그래프, 수영 CSS 페이스 그래프 |
| 정보 | 프로그램 시작일, 시설 정보(전화 바로 걸기), 확인할 일·준비물 체크리스트, JSON 백업 내보내기·가져오기 |

## 파일 구성

```
index.html          화면 뼈대와 하단 탭
style.css           모바일 우선 스타일, 다크모드 자동 지원
app.js              화면 렌더링, 기록 저장, 타이머, 백업
data.js             루틴·타임라인·주차 계획·시설·체크리스트 데이터
manifest.json       홈 화면 앱 설정
service-worker.js   오프라인 캐시
icons/              앱 아이콘(192·512px)
.nojekyll           GitHub Pages가 파일을 그대로 배포하도록 함
```

## 루틴 바꾸기

`data.js`만 고치면 됩니다.

- 운동 추가·수정: `workouts.A.exercises` 등에 `{ id, name, sets, reps, rpe, rest, load, cue }` 형식으로 적습니다. `rest`는 초 단위입니다.
- 영상 링크: 운동·수영 블록 이름을 누르면 유튜브에서 "이름 + 자세"로 검색합니다. 검색어를 바꾸려면 그 항목에 `video: "검색어"`를 적습니다.
- 요일 바꾸기: `schedule`의 숫자(0=일 … 6=토)와 운동 키를 바꿉니다.
- 주차 강도: `weeks`의 `rpe`, `setDelta`, `volumeFactor`, `swimPct`, `cssDelta`를 조정합니다.
- 운동 `id`는 기록과 그래프를 잇는 열쇠입니다. 이름만 바꿀 때는 `id`를 그대로 두세요.
- 배포 후 휴대폰에 바로 반영되게 하려면 `service-worker.js`의 `CACHE` 값(예: `lunch-workout-v2` → `v3`)도 올려 주세요.

## 로컬에서 실행

서비스 워커는 `file://`에서 동작하지 않으므로 로컬 서버로 엽니다.

```powershell
python -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다. 개발자 도구의 기기 모드(375×812)로 휴대폰 화면을 확인할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다(`workout`). 공개(Public) 저장소여야 무료 플랜에서 Pages를 쓸 수 있습니다.
2. 이 폴더를 올립니다.

   ```powershell
   git remote add origin https://github.com/jsyunn1/workout.git
   git branch -M main
   git push -u origin main
   ```

3. 저장소의 **Settings → Pages**에서 **Source: Deploy from a branch**, **Branch: `main` / `/(root)`**를 고르고 저장합니다.
4. 1~2분 뒤 `https://jsyunn1.github.io/workout/`에서 열립니다. 모든 경로가 상대 경로라 하위 경로에서도 그대로 동작합니다.

## 휴대폰 홈 화면에 추가

**iPhone (iOS Safari)**

1. Safari로 배포 주소를 엽니다(다른 브라우저 앱에서는 홈 화면 앱으로 설치되지 않을 수 있습니다).
2. 아래쪽 **공유** 버튼(네모에 위쪽 화살표)을 누릅니다.
3. **홈 화면에 추가**를 누르고 이름을 확인한 뒤 **추가**를 누릅니다.

**Android (Chrome)**

1. Chrome으로 배포 주소를 엽니다.
2. 오른쪽 위 **⋮** 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
3. **설치**를 누르면 홈 화면에 아이콘이 생깁니다.

한 번 열어 두면 이후에는 인터넷 없이도 실행됩니다.

## 데이터와 백업

- 기록·설정·체크 상태는 그 기기 브라우저의 localStorage에만 저장되며 서버로 보내지 않습니다.
- iOS는 홈 화면 앱과 Safari의 저장 공간이 따로이고, 오래 쓰지 않으면 데이터가 지워질 수 있습니다. **정보 탭 → 내보내기**로 가끔 백업해 두세요.
- 다른 기기로 옮길 때는 백업 JSON을 **가져오기**로 불러옵니다(현재 데이터를 덮어씁니다).

## 참고

- 휴식 타이머의 진동은 Android에서만 동작합니다(iOS Safari는 진동 API 미지원). 소리는 무음 모드에서 들리지 않을 수 있습니다.
- 운동 프로그램은 일반적인 가이드입니다. 통증이 있으면 전문가와 상담하세요.
